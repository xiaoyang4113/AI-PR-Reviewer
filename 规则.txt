题目一：语音版的日历工具



请开发一个语音日历工具，帮助用户提高日历管理的效率和便捷性。

要求：请了解用户在日历管理中的真实需求，设计并实现一个以语音交互为核心的日历管理工具，能准确、顺畅地实现通过语音添加/删除/查看事件提醒等能力。



题目二：多平台内容发布工具



很多创作者需要在公众号、知乎、B站、小红书等平台同步发布内容，但格式适配很麻烦。请设计并实现一个工具，帮助创作者提升发布效率和便捷性。

要求：用户在工具中输入内容，可自动适配各平台格式与风格，并支持一键发布（可选模拟发布）。需给出扩展更多平台的架构设计。



题目三：AI PR Review 助手


请开发一个 AI 代码评审工具，帮助开发者提升 Pull Request 的 Review 效率与质量。

要求：请了解开发者在代码评审中的真实需求，设计并实现一个以 AI 辅助分析为核心的工具。用户指定 GitHub PR，系统自动获取代码变更并智能分析，辅助发现问题。需支持 PR 变更总结、风险代码识别、Review 建议生成等。请综合考虑分析准确性、上下文理解、误报与漏报控制、响应速度及使用体验等关键因素，并在作品中说明系统在模型选择、上下文获取方式及未来扩展方向上的设计思路。

03 作品提交规则



请滑动以下内容，完整阅览并知悉细则：



3.1 须提交内容
公开的github/gitee仓库
（过程保密防抄袭；提交截止后可公开访问，以便评委评审作品）
demo视频
README文档


3.2 作品有效性

作品需符合所选议题方向，并确保自主完成无抄袭。

全周期持续交付，严禁临尾“突击提交”。从议题发布之日起，开发周期内保持持续的PR（Pull Request）记录和 commit 提交。仅在最后一天一次性导入所有代码的作品，将直接视为无效作品。

所有commit 时间戳必须落在所选批次的开始与截止时间之内，否则视为无效作品。

其他无效情形：① PR 描述空白或与实际代码变更严重不符；② 引用了第三方库或框架，没在 README 中列明依赖，且未说明原创功能部分；③ 复用了自己过去的代码片段，没在 PR 描述中注明来源。



3.3 PR（Pull Request）提交规范

请基于 PR 添加新功能。

每个PR只做一件事：每个 PR只实现或修改单一功能；鼓励尽可能小、粒度尽可能细的 PR；大功能应拆分为多个独立 PR 分步提交。

PR标题与描述需清晰完整，内容包含：

① 标题：一句话说明本 PR 新增/修改了什么。

② 功能描述：说明该功能的作用与使用方式。

③ 实现思路：简要说明技术选型或核心实现逻辑。

④ 测试方式：如何验证该功能正常运行。

PR合并后，主分支代码需保持可运行状态，评委在任意时间查看应能复现演示效果。



3.4 Demo视频要求

请用声音完整讲解、展示作品主要功能和效果，覆盖核心模块。

请上传至可访问的外部平台例如 bilibili/云盘等，链接放到代码仓库的README中，视频可播放。



3.5 其他要求

若多人组队，每队仅需提交一个代码仓库地址。队员均须使用各自账号提交commit，PR清晰描述各自分工。

如项目包含多个独立模块，应提交至同一仓库的不同子目录（如 /frontend 与 /backend）分别管理，以便于部署和启动

代码仓库需在开题后创建。



3.6 关于知识产权与学术诚信

除另行说明，作品的知识产权归提交队伍或个人所有。

同学们应自觉遵守知识产权的有关法规，不得侵犯他人的知识产权或其他权益， 不得未经相关单位许可对外共享或公开发布涉及该单位知识产权的作品及软件。如造成不良后果，相关法律责任由提交人自行承担，七牛云不负任何法律责任。

请同学们遵守学术诚信。一经确认代码抄袭或技术抄袭等学术不端行为，或代码重复率在 50% 以上，将取消路演资格，并列入招聘黑名单。

04 FAQ



1. 这个实训营到底是干嘛的？

这是七牛云发起、面向在校及往届学生的实战成长项目，简单说：这不是培训班，也不是传统实习——7月开营，为期2个月，你会直接参与七牛云真实项目的开发，由行业大牛带教，按企业级工程标准设计并交付产品。干得好，直通校招offer。



2. 有多少校招offer名额？哪些方向？

本次实训营预计开放 100+ 正式校招offer直通名额，涵盖前端、后端、全栈、产品经理、技术销售等方向，优秀候选人绝不错过。



3. 我能报名吗？有学历和专业限制吗？

面向2025-2029届所有在校及往届学生，不限学历、不限背景，看的是你的实力和学习能力。往届同学实训期间将以顾问合作形式发放津贴。



4. 议题什么时候出？错过这批还有机会吗？

至少3个批次（5.23 / 5.29 / 6.5 /…），在所选批次议题发布后24小时内重新进入你的报名表单「修改结果」提交代码仓库地址（GitHub / Gitee / 其他开源平台），开发周期72小时，需完成MVP，有余力可拓展不设上限。名额招满即止，建议尽早参与。



5. 提交作品后还有面试吗？什么形式？

有的。每个批次作品提交截止后，我们会尽快完成评审，通过的同学会收到路演交流的通知，具体时间以短信/邮件/群消息为准。作品评审通过后会进入路演交流环节，你需要围绕自己的作品，讲清楚为什么这样设计、开发过程中遇到了什么问题、怎么解决的，主要将围绕着作品、你的思考等开展交流。



6. 有钱拿吗？需要交费吗？

全程免费，不收取任何费用！每一步都有回报——3天限时开发的优秀作品有机会赢得项目奖金，入营后日津贴 300 元/天，实训营最终评选还有机会瓜分 20w+ 奖金池。
